🌤️ weather-app

Um site de previsão do tempo desenvolvido para praticar HTML, CSS e JavaScript.

📌 Sobre o projeto

O weather-app permite pesquisar uma cidade e visualizar informações sobre o clima em tempo real, utilizando a OpenWeather API.

✨ Funcionalidades

- 🔎 Pesquisa por cidade
- 🌡️ Temperatura atual
- ☀️ Descrição do clima
- 🔥 Temperatura máxima
- ❄️ Temperatura mínima
- 💧 Umidade do ar
- 💨 Velocidade do vento
- 📱 Interface adaptada para celular
- 🎨 Interface moderna e responsiva

🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Font Awesome
- Google Fonts

📂 Estrutura do projeto

🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo "index.html" no navegador.
4. Pesquise o nome de uma cidade.

🌎 API

Este projeto utiliza a OpenWeather API para obter os dados meteorológicos.

📚 Objetivo

Este projeto foi desenvolvido como parte dos meus estudos de JavaScript e desenvolvimento web, com o objetivo de praticar consumo de APIs, manipulação do DOM, eventos e estilização com CSS.
